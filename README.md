# Blockchain-based-Charity-Donation-Platform
The Blockchain-Based Charity Donation Platform is a Flask-powered web application that facilitates secure and transparent fund transfers using Ethereum and Web3 technologies. Designed with a philanthropic mission, this platform enables users to donate cryptocurrency to support underprivileged children in need of help from compassionate individuals across the globe.

Key features include:

 Wallet Integration: Users can connect their Ethereum wallets directly to the platform.

 Real-Time Balance Check: Instantly view wallet balances through Web3 integration.

 Secure Fund Transfers: Donate ETH to verified Ethereum addresses with transaction tracking.

 Transparency & Security: Leveraging blockchain to ensure tamper-proof, traceable donations.

This application combines the power of blockchain with social impact, ensuring every donation reaches its intended cause transparently and efficiently.

How to Use
The Payment App offers a user-friendly interface for managing and transferring Ethereum securely. Here’s how users can interact with the application:

Connect Your Wallet
Start by linking your MetaMask wallet to the application. This step is essential to access blockchain functionalities.

View Wallet Balance
Once connected, your Ethereum wallet balance is fetched and displayed in real-time using Web3.

Send ETH to Others
Enter a recipient's Ethereum address and the amount you'd like to send. On successful transfer, a confirmation modal will show:

Amount sent

Transaction hash (ID) for reference

Quick Mobile Access
A QR code is provided, allowing users to quickly access the application through mobile Ethereum wallet apps by simply scanning the code.
